# One Sentence for a Traveler from 1800

A single sentence that explains the modern internet to a traveler from the year 1800, built only from things their world already holds — the post road, the letter, and the library — with one image to carry it: a letter that arrives before its ink can dry.

Bounty: https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb

## Run it

```sh
node main.ts
```

This writes the sentence (UTF-8, within the 1–200 character gate) to `/output/entry.txt`. The entrypoint is pure Node.js standard library and deterministic: the same sentence on every run.
